📐 인터랙티브 수학 학습터 (Interactive Math Learning Apps)

고등학교 1학년 수학 교육과정에 맞춘 인터랙티브 시각화 학습 도구 모음입니다.
학생들이 단순히 공식을 암기하는 것에서 벗어나, 직접 화면을 터치하고 도형을 조작해 보며 수학의 원리를 직관적으로 깨우칠 수 있도록 설계되었습니다.

✨ 주요 특징 (Features)

📱 모바일 & 태블릿 최적화: PC뿐만 아니라 교실에서 학생들이 주로 사용하는 스마트폰과 태블릿의 터치 환경에서도 완벽하게 동작합니다.

🖱️ 직접 조작하는 수학 (Interactive): 슬라이더를 움직이거나 점을 드래그하면, 그에 맞춰 도형과 결괏값이 실시간으로 반응합니다.

📝 단계별 학습 구조: 관찰 및 실험 ➡️ 결과 예측 ➡️ 시각적 확인 ➡️ 수식(MathJax)을 통한 엄밀한 증명의 4단계로 구성되어 깊이 있는 학습이 가능합니다.

⚡ 가볍고 빠른 구동: 별도의 앱 설치나 서버 연동 없이 HTML, CSS, JavaScript만으로 브라우저에서 즉시 실행됩니다.

📚 수록된 학습 앱 (Contents)

1. 삼각형 내각 및 외각의 이등분선 정리 (angle-bisector.html)

목표: 각의 이등분선의 비례식($AB : AC = BD : CD$) 증명

내용: 보조선을 긋고 평행선의 성질(동위각, 엇각) 및 이등변삼각형을 유도하여 비례식이 성립하는 과정을 시각적으로 확인합니다.

2. 무게중심은 왜 움직이지 않을까 (centroid.html)

목표: $m:n$ 내분 삼각형의 무게중심의 성질 이해

내용: 원래의 삼각형 ABC의 각 변을 $m:n$으로 내분하여 새로운 삼각형 DEF를 만듭니다. 슬라이더로 $m, n$의 비율을 변경해도 두 삼각형의 무게중심(G)이 일치함을 관찰하고, 좌표 계산을 통해 이를 증명합니다.

3. 두 직선에서 같은 거리에 있는 점의 자취 (locus-of-equidistant-point.html)

목표: 자취의 방정식 개념 및 각의 이등분선 이해

내용: 임의의 점을 움직여 두 직선까지의 거리를 비교해 봅니다. 두 거리가 같아지는 조건에 맞는 점들을 모으면 서로 직교하는 두 개의 각의 이등분선이 됨을 실험과 수식으로 증명합니다.

🛠️ 기술 스택 (Tech Stack)

HTML5 & CSS3: 화면 구조 및 반응형 레이아웃 구성

Vanilla JavaScript: 도형 렌더링(SVG/Canvas) 및 실시간 터치/마우스 이벤트 처리

Tailwind CSS: 직관적이고 깔끔한 UI/UX 스타일링

MathJax: 웹 표준 기반의 깔끔한 수학 수식 렌더링
