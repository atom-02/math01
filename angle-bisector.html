삼각형의 각의 이등분선 정리와 증명

아래 도형에서 평행선(빨간색 점선)과 각의 크기(파란색/녹색 부채꼴)를 확인해 보세요.

← 목록으로 돌아가기

1. 내각의 이등분선 정리

AB : AC = BD : CD
  • 보조선: 점 C에서 선분 AD와 평행하게 선을 긋고, 연장된 BA와 만나는 점을 E로 둡니다.
  • 평행선의 성질: AD // EC 이므로
    ∠BAD = ∠AEC (동위각), ∠CAD = ∠ACE (엇각)
  • 이등변삼각형 유도: 따라서 ∠AEC = ∠ACE 가 되어 △ACE는 AC = AE 인 이등변삼각형이 됩니다.
  • 비례식 결론: △BCE에서 평행선 길이에 비례에 따라 BA : AE = BD : CD. AE 자리에 AC를 넣으면 증명 완료!

2. 외각의 이등분선 정리

AB : AC = BD : CD
  • 보조선: 점 C에서 외각의 이등분선 AD와 평행하게 선을 그어 선분 AB와 만나는 점을 E로 둡니다.
  • 평행선의 성질: AD // EC 이므로
    ∠FAD = ∠AEC (동위각), ∠DAC = ∠ACE (엇각)
  • 이등변삼각형 유도: 따라서 ∠AEC = ∠ACE 가 되어 △ACE는 역시 AC = AE 인 이등변삼각형이 됩니다.
  • 비례식 결론: 큰 △ABD에서 평행선 비례 원리에 따라 BA : EA = BD : CD. EA 자리에 AC를 넣으면 증명 완료!
