자취의 정체 파악하기

우리가 찍었던 점들을 이으면 어떤 모양이 되나요? 정답 버튼을 눌러 점들이 만들어낸 도형의 진짜 정체를 확인해 보세요.

수식으로 증명하기

눈으로 확인한 사실을 식으로 증명해 봅시다. 이것이 바로 '자취의 방정식'을 구하는 과정입니다.

1. 조건 설정

\[ L_1:\ 2x - y = 0 \quad / \quad L_2:\ x + 2y = 0 \]

2. 점과 직선 사이의 거리 공식 적용

점 \( P(x, y) \)에서 두 직선에 이르는 거리가 같아야 하므로, \( d_1 = d_2 \) 가 성립합니다.

\[ \frac{|2x - y|}{\sqrt{2^2 + (-1)^2}} = \frac{|x + 2y|}{\sqrt{1^2 + 2^2}} \quad \Rightarrow \quad |2x - y| = |x + 2y| \]

3. 자취의 방정식 도출

절댓값 기호를 풀 때는 우변에 \( \pm \) 기호가 붙습니다.

경우 1: \( +\) 일 때

\[ 2x - y = x + 2y \quad \Rightarrow \quad x - 3y = 0 \]

경우 2: \( -\) 일 때

\[ 2x - y = -(x + 2y) \quad \Rightarrow \quad 3x + y = 0 \]
결론적으로 우리가 구한 자취는 \( x - 3y = 0 \) 과 \( 3x + y = 0 \) 두 개의 직선입니다. 두 기울기의 곱이 -1이므로 서로 직교하는 각의 이등분선이 됩니다.
